# X2 — Interfaz de sistemas
- narrador/sistemas/index.js: registro de módulos `{id, iniciar(estado, ctx) → sub, turno(sub, entrada, rng) → {texto, sub, terminado}, resultado(sub) → efectos[]}`.
- El estado de partida guarda a lo sumo un sistema activo (`sistema: {id, sub}`); mientras está activo, la entrada del jugador va al módulo; «salir/irme/dejar» lo cierra si el módulo lo permite.
- Efectos con los tipos existentes de resolver (DINERO, hechos, relación, objeto) + nuevos solo si hacen falta (anotar).
- Pensado para combate y minijuegos futuros (pesca, dados, cerraduras) y para que el juego principal pueda dibujar UI propia leyendo `sub`.
- Tests: ciclo completo con un módulo falso, persistencia en el estado, cierre forzado.
