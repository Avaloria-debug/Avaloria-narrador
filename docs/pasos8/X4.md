# X4 — Regateo (primer módulo de sistema)
- Se abre con «regatear», «más barato», «rebaja», «te doy N por X» frente a un vendedor.
- Opciones: pedir rebaja, ofrecer monto, ofrecer trueque, pagar de más, aceptar, irse.
- El NPC responde con t41 `regateo.<npc>.(acepta|rechaza|contraoferta)` según rasgo `dinero` de valores.json, relación y `regateo.rebaja_max_por_rasgo_dinero`. Máx. 3 rondas; insistir de más baja relación.
- Pagar de más sube relación (+`pagar_de_mas_relacion`). Trueque: valor del objeto según precios.json y el interés del NPC (hallazgos valen más para Ivor y Maren).
- Neutral: el NPC acepta solo si le conviene. Tests por NPC y casos límite.
