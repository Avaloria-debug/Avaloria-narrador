# V5 — Defaults y aclaración
- Defaults: «hablar»/«preguntar» sin NPC → único NPC presente; «mirar/tocar» sin objeto → último foco; un solo candidato visible → ese.
- Aclaración: ≥2 candidatos → «¿El X o el Y?» con nombres del alias; sin objeto y sin default → «¿Qué querés <verbo>?». Respuesta corta del jugador («el de la plaza», «el primero», «la gata») resuelve la pregunta pendiente.
- Textos de aclaración `prov`.
