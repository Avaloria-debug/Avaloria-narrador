# V7 — Varias acciones, negación y modo
- Separar por «y», «y después», «luego», «, » cuando cada parte tiene verbo; ejecutar en orden, la 2ª usa las referencias de la 1ª. Máx. 3 acciones por frase.
- Negación: «no sigo a X» → ignorar X; «no le digo nada» → callar.
- Modo: despacio, a escondidas, en silencio → `modo: sigilo`; rápido, corriendo → `modo: prisa`. Solo se pasa como dato; el efecto lo decide el motor existente si lo soporta (si no, se ignora y se anota).
