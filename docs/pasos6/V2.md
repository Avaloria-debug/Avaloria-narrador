# V2 — Lematizador y enclíticos
- Reglas para voseo, tuteo, usted, infinitivo, imperativo, gerundio y pasado simple de los verbos de acción: mirá/mira/mire/mirar/miro/miré/mirando → mirar.
- Separar enclíticos: mirala, agarralo, preguntale, dáselo → verbo + pronombre (lo pasa a V4).
- Tests por verbo; sin romper palabras que no son verbos (lista de excepciones).
