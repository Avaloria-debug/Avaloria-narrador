# S4 — Ramas y finales
- Ejecutar `ramas.<verbo>` del foco: un paso por acción, en orden; cada paso puede traer `tiempoMin` (avanza el reloj), `emite` (activa focos nuevos) y `fin` (`nada` = pérdida de tiempo; `hallazgo` = marca `estado.marcas.foco_<id>_hallazgo`, sin crear objetos nuevos).
- Rama de pasos como string o como objeto {t,...}. Si el foco no tiene rama para el verbo → usar `clases.<clase>.<verbo>` (variante por rng derivado).
- Tras `fin` o si ya está `agotado`, repetir la acción → `clases.<clase>.ignorar` y no avanza reloj.
- Cada acción sobre un foco es un turno normal: tensión, hechos y rumores siguen su curso (ninguna rama los salta).
- Para NPC presentes, mantener el tono de la escena (franja/clima) en el texto de cierre vía ambiente existente; sin texto nuevo en código.
